# micro:bit Example Code for Students

## Description
This repository contains simple example programs used during lectures for kids learning how to program the BBC micro:bit. The code is intended to be copied, pasted, and run directly on the students' microcontrollers.

The goal of the repository is to provide easy-to-understand examples that demonstrate basic programming concepts and simple hardware interactions using the micro:bit.

## Purpose
The repository serves as a small collection of reference examples for students who attended the lectures. Students can use the files to experiment, modify the programs, and better understand how the micro:bit works.

## Usage
1. Open the micro:bit editor (MakeCode or another supported editor).
2. Copy the code from one of the files in this repository.
3. Paste it into the editor.
4. Compile the program.
5. Upload the generated file to the micro:bit.

Students are encouraged to modify the examples and experiment with their own ideas.

## Repository Content
The repository includes small standalone programs demonstrating different micro:bit features such as:
- LEDs and display patterns
- Buttons
- Basic input/output
- Simple interactive behavior

Each file can be used independently.

## Requirements
- BBC micro:bit
- Mikrobit - Tinkerkit
- A computer with USB connection
- micro:bit MakeCode editor or another compatible development environment
